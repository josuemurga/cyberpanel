### Imunify - Automated Cybersecurity for Linux Web Servers.

Imunify is a complete, multi-layered web server security platform that combines intelligent antivirus, security monitoring, and automated protection against a wide range of threats.

**Key Features:**

-   Advanced firewall/WAF with machine learning rulesets
-   Intrusion Detection and Prevention System (IDS/IPS)
-   Automatic virus and malware scanning and removal
-   Malicious PHP script detection and blocking with the "Proactive Defense" component
-   Rebootless kernel patch updating with the "KernelCare" component
-   Domain reputation and blacklist status monitoring
-   Seemless web hosting control panel integration

**Protection against various attack types:**

-   Brute-force attacks at both network and HTTP levels
-   Vulnerability exploitation, including 0-day attacks
-   Denial of Service (DoS) attacks
-   Port scanning
-   Other types of threats

**Benefits:**

-   Fully automated operation ensures server safety and minimizes human error
-   AI-powered "herd protection" aggregates and leverages threat intelligence from other installations
-   Integrated security console built into your hosting control panel
-   Convenient and robust CLI for automation and reporting
-   World-class 24/7/365 technical support included

**Additional Capabilities:**

-   Free version includes a fully-featured malware file scanner, reputation, and blacklist status monitoring
-   Premium version enables one-click automatic cleanup, scheduled website checks, admin and user notifications on malware detection, and user permissions management
-   Supports WordPress, Joomla!, Magento, Drupal, MODx, Bitrix, and other PHP-based CMSs as well as static HTML websites
-   UI optimized for security monitoring of hundreds of users and thousands of domains per server.

Imunify provides a comprehensive solution for web server security, combining the best features of antivirus protection and monitoring with advanced cybersecurity technologies.
